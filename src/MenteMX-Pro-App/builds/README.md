# 📦 Builds — MenteMX Pro

Pasta para armazenar os pacotes de instalação gerados.

## Estrutura
```
builds/
├── android/          # APKs e AABs
│   └── mentemx-pro-v1.0.0.apk
├── desktop/          # Executáveis Windows/Mac
│   └── MenteMX-Pro-Setup-1.0.0.exe
└── README.md
```

## Como gerar
- APK: `.\build-apk.ps1`
- Desktop: `.\build-desktop.ps1` (futuro)
